Journal des setups

Chaque jour, Desk Key envoie le setup de chaque actif : niveaux du pré-marché, Judas, cassure, entrée, SL, TP 2R / 2,5R / 3R, puis le résultat simulé exactement comme le backtest (pour l'or : trade 1 avec son stop remonté, plus le second trade). Colonne « Délai » : minutes entre la cassure et la touche du 50 % (en couleur au-delà de 20 min ; sur 3 ans, ces touches lentes ont été meilleures sur les indices, pas sur l'or : piste suivie, pas une règle). Colonne « Feu » : état du feu rouge de l'indice ce jour-là (somme des 10 setups précédents à 3R) ; sous feu rouge, la règle est suivie à blanc et ne compte pas dans le résultat « tel que tradé ». Les trades pris avec Desk Key sont reliés automatiquement à leur setup (résultat réel à côté). Avant l'installation de Desk Key, le journal est complété par le moteur de backtest (mêmes règles, mention « backtest ») depuis décembre 2023 : périodes 1 an, 2 ans, 3 ans. Cliquez sur une ligne pour voir le détail.

Connexion MT5

Desk Key (exécution en une touche)

  1. Télécharger Desk Key et la dernière version du robot DeskUS_Bridge (1.06 : il transmet votre clé à Desk Key et exporte aussi US30 et XAUUSD pour les backtests).
  2. Copier les deux fichiers dans MQL5 → Experts (Fichier → Ouvrir le dossier des données), puis les compiler dans MetaEditor.
  3. Ouvrir un graphique M1 par indice (US100.cash, US500.cash) et glisser Desk Key sur chacun : le profil se choisit tout seul et refuse un symbole qui ne correspond pas.
  4. Cocher « Autoriser le trading algorithmique » (nécessaire même pour l'exécution en une touche) et régler le risque par trade.
  5. Touche K : placer l'ordre (ou l'armer avant 10:00 NY) · X : annuler · bouton – : réduire le panneau · HISTO : setups passés sur le graphique · PÉRIODE : 7, 30, 90 ou 250 séances.
  6. RISQUE : montant, % du solde ou lot fixe, réglable dans le panneau (– / + ou saisie). TESTER LES NOTIFS : notification sur le téléphone (application MT5), Telegram ou WhatsApp. Mode d'emploi : règles, section Notifications.

Desk Key envoie ses setups ici tout seul (même adresse autorisée que le robot DeskUS_Bridge). Le mode automatique est désactivé par défaut.
